# たけのこニョッキ

各プレイヤーが自分の端末から参加する6席のWebゲームです。遊び方は [RULES.md](RULES.md)、Web版の詳細は [SPEC.md](SPEC.md) を参照してください。

## 遊び方

1. 進行役が名前を入力して部屋を作り、表示された招待リンクまたは8文字の部屋コードを共有します。
2. 参加者は各自のスマートフォンやPCで部屋に入ります。空席はCPUが担当します。
3. 進行役が対戦を開始します。カウントダウンが終わったら、ほかの人と重ならないようにコールボタンを押します。開始前の押下はフライングです。
4. 同時コールや最後まで残った席はドボンになります。3回ドボンになると敗北です。進行役は結果を確認して次のラウンドを始めます。

参加受付中に罰ゲームモードとドボンカードを設定できます。各プレイヤーは同じ盤面を自分の端末で確認でき、通信が切れた場合は再接続またはCPUへの交代で進行します。対戦には全員のインターネット接続が必要です。

## ローカル起動

Node.js 22以上と pnpm 11を用意します。

```sh
pnpm install
pnpm build
pnpm dev:server
```

表示されたローカルURLを開きます。画面のホットリロードが必要な場合は、別の端末で `pnpm dev` も起動し、ViteのURLを開いてください。Viteは `/api` をローカルのWrangler（ポート8787）へ転送します。

```sh
pnpm test
```

2人の参加と切断時の動作を検証する場合は、ローカルサーバーを起動した状態で `pnpm test:integration` を実行します。進行役の切断後30秒を待つため、完了まで約40秒かかります。

## 公開

CloudflareアカウントでWranglerにログイン後、`pnpm deploy` を実行します。Workers Static Assetsが画面を、Durable Objectが各部屋を提供します。公開後にiPhoneのSafariから招待リンクを開いて参加できます。ホーム画面への追加にはHTTPSでの公開が必要です。

部屋のカードと対戦状態はサーバー内にあり、端末に残るのは参加情報と作成者のカード一覧です。アカウント登録はありません。部屋コードを知る人は参加できるため、招待リンクは遊ぶ相手だけに共有してください。
